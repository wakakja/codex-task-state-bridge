# 本机桌宠增强功能与公开范围

原项目：[jingh12312-rgb/bailong-desktop-pet](https://github.com/jingh12312-rgb/bailong-desktop-pet)。本机修改基于 v0.4.1，最后整理的本地增强版本号为 `0.4.1-codex-sync.7`。

| 本机新增或修改的效果 | 独立仓库包含的内容 |
| --- | --- |
| Codex 多对话运行数量核对，补上漏掉的任务，移除已结束任务 | `codex_activity.py`，每个主对话最新轮次的只读状态查询 |
| 工作气泡显示真实对话名字 | `codex_titles.py`，只读对话名称查询 |
| 将状态输出给其他程序 | `cli.py`，JSON 单次输出和定期输出 |
| 开始、完成、中断事件通过本机通信交给桌宠，重启期间暂存事件 | 仅记录本机实现效果，未包含原桌宠的接收端改动 |
| 桌宠缩小到原来的约 70%（179×179）并保存位置 | 仅记录本机实现效果，未发布派生界面源码 |
| 待机每约 12–24 秒随机播放互动动作 | 仅记录本机实现效果，不发布原动画 |
| 工作时坐下，只循环 work02 中间敲电脑的片段，结束后收电脑起身 | 仅记录播放逻辑，不发布原动画或修改版播放器 |
| 工作气泡持续显示，对话名字末尾显示小转圈，移除底部进度条 | 仅记录本机界面效果 |
| Windows 登录后监听 Codex，异常退出后恢复，自启动切到新版 | 仅记录本机安装配置，不发布依赖原程序的安装器 |
| 任务过程中保持位置，不再跳到屏幕中间 | 仅记录本机修复效果 |

本仓库仅含独立模块，不是可直接替换 `BailongPet.exe` 的发布包。下载本仓库不会自动获得表格中全部桌宠界面效果。完整派生版需在取得原项目相应授权后另行处理。
